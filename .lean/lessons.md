# Lessons (every junior reads these; add with `lean lesson`)
- Clamp Double-to-UInt64 conversions (timeouts) so .infinity or huge values do not trap. (MT-5, claude@Kevins-MacBook-Air, 2026-11-14)
- Test runners that never yield the main actor between tests expose races with unawaited @MainActor Tasks; pause between tests and add a self-test regression. (MT-0, claude@Kevins-MacBook-Air, 2026-11-14)
- Grep for an existing method of the same name before adding one to a large class; a duplicate declaration blocks every build and test. (MT-1, claude@Kevins-MacBook-Air, 2026-11-14)
- Optional hint fields in decoded API payloads need a lenient try? decode, because a String? field still throws on a type mismatch. (MT-4, claude@Kevins-MacBook-Air, 2026-11-14)
- TeamEvent.groupMove title counts movers only (moves.count), not notMoved or unchecked peers. (MT-3, claude@Kevins-MacBook-Air, 2026-11-14)
- A view that stores a selected key must re-check it against the live choice list on every use, because a removed team otherwise leaves a stale selection that still drives the load. (MT-8, claude@Kevins-MacBook-Air, 2026-11-14)
- A reviewer that returns PASS must also rewrite verdict.md; the merge worker reads that file, so a stale FAIL left there blocks a passed task. (MT-2, claude@Kevins-MacBook-Air, 2026-11-15)
- A test that claims "skipped because of condition C" must fail when you delete the line that sets up C. Run that one mutation before handover. (MT-6, claude@Kevins-MacBook-Air, 2026-11-17)
- TeamTracker never probes the current pair, so any rule that changes which profile the single-mode loop shows must still fetch liveTarget() every pass; prove it with a real tracker and a probe round where a small riser would otherwise take over. (MT-7, claude@Kevins-MacBook-Air, 2026-11-17)
- When you change a format specifier, check that each call site's argument type matches the new specifier. (FU-3, claude@Kevins-MacBook-Air, 2026-11-17)
- Test clocks run ahead of the wall clock, so any rule that compares ClaudeUsage.lastUpdated (stamped with Date()) with the tracker's now needs fakes to set lastUpdated explicitly. Packets should also list the fixture files they expect to change. (FU-1, claude@Kevins-MacBook-Air, 2026-11-17)
- A single-flight gate that drops passes must check the tracker's live target again after it releases and re-run only for a different pair (compare profile id and org id). TeamTracker fires onCurrentChanged synchronously while the gate is still held, so without that check the new current pair waits a full timer interval. (FU-2, claude@Kevins-MacBook-Air, 2026-11-17)
